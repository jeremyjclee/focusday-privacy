FocusDay 계정 및 데이터 삭제 요청

시행일: 2026년 11월

이 페이지는 FocusDay 사용자가 앱 계정과 계정에 연결된 데이터를 삭제 요청할 수 있도록 제공되는 공개 웹 리소스입니다.

앱에서 바로 삭제
FocusDay Android·데스크탑 앱의 설정 > 계정 삭제에서 본인 확인 후 계정과 서버 데이터를 바로 지울 수 있습니다. 이메일·Google·카카오·네이버 로그인 모두 해당합니다.

삭제 요청 접수
이메일로 삭제 요청 보내기
요청 시 FocusDay 계정 이메일 주소와 "계정 및 데이터 삭제 요청"이라는 제목을 포함해 주세요.

삭제되는 데이터

  • Firebase Authentication 계정 식별 정보
  • 이메일 주소, 표시 이름, Firebase UID 등 계정 정보
  • Firestore에 저장된 할 일, 목록, 프로젝트, 마일스톤, 습관, 습관 완료 기록, 운동 기록, 운동 템플릿, 메모, 집중·시간 기록
  • 프로필, 기기 알림 연결(설치 ID·푸시 토큰), 개인정보 동의 기록
  • 사용량 카운터, 프리미엄 등록(이메일 포함)
  • 그 계정으로 보낸 의견 보내기 기록(내용, 답장 이메일, 기기 정보)과 첨부 스크린샷

계정 삭제로 지워지지 않는 데이터

  • 운영자 메일로 전달된 의견 사본과 로그인하지 않고 보낸 의견: 위 메일로 요청하면 삭제합니다.

기기에 남아 있을 수 있는 데이터

앱에서 계정을 삭제하면 그 기기에 저장된 이 계정의 데이터도 함께 지워집니다. 같은 계정으로 로그인했던 다른 기기의 데이터는 그 기기에서 FocusDay 앱 데이터를 삭제하거나 앱을 제거하면 삭제할 수 있습니다. 기기 캘린더에 사용자가 직접 생성 또는 동기화한 이벤트는 캘린더 앱 또는 FocusDay의 캘린더 동기화 기능에서 별도로 삭제해야 할 수 있습니다. Windows 앱의 로그 파일은 이 컴퓨터의 %APPDATA%/FocusDay/logs에 남고 이메일과 UID는 가려져 있습니다.

처리 절차

  1. 앱을 쓸 수 없는 경우 사용자가 위 링크로 삭제 요청을 제출합니다.
  2. 개발자는 요청 계정의 본인 확인을 위해 추가 확인 정보를 요청할 수 있습니다.
  3. 요청을 받은 날부터 10일 이내에 계정과 연결된 서버 데이터를 삭제하고 결과를 메일로 알려 드립니다.
  4. 법령 준수, 보안, 분쟁 대응, 부정 사용 방지 등 정당한 사유가 있는 일부 데이터는 필요한 기간 동안 제한적으로 보관될 수 있습니다.

관련 문서

자세한 데이터 처리 내용은 FocusDay 개인정보처리방침을 확인해 주세요.
