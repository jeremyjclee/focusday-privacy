FocusDay 계정 및 데이터 삭제 요청

시행일: 2026년 6월 9일

이 페이지는 FocusDay 사용자가 앱 계정과 계정에 연결된 데이터를 삭제 요청할 수 있도록 제공되는 공개 웹 리소스입니다.

삭제 요청 접수
GitHub Issues에서 삭제 요청 작성
요청 시 FocusDay 계정 이메일 주소와 "계정 및 데이터 삭제 요청"이라는 제목을 포함해 주세요.

삭제되는 데이터

  • Firebase Authentication 계정 식별 정보
  • 이메일 주소, 표시 이름, Firebase UID 등 계정 정보
  • Firestore에 저장된 할 일, 목록, 체크리스트, 프로젝트, 마일스톤, 습관, 습관 완료 기록, 운동 기록
  • 계정과 연결된 피드백 및 문의 기록 중 삭제 대상 데이터

기기에 남아 있을 수 있는 데이터

기기 로컬 저장소의 앱 데이터는 Android 설정에서 FocusDay 앱 데이터를 삭제하거나 앱을 제거하면 삭제할 수 있습니다. 기기 캘린더에 사용자가 직접 생성 또는 동기화한 이벤트는 캘린더 앱 또는 FocusDay의 캘린더 동기화 기능에서 별도로 삭제해야 할 수 있습니다.

처리 절차

  1. 사용자가 위 링크로 삭제 요청을 제출합니다.
  2. 개발자는 요청 계정의 본인 확인을 위해 추가 확인 정보를 요청할 수 있습니다.
  3. 확인이 완료되면 계정과 연결된 서버 데이터를 합리적으로 가능한 기간 내 삭제합니다.
  4. 법령 준수, 보안, 분쟁 대응, 부정 사용 방지 등 정당한 사유가 있는 일부 데이터는 필요한 기간 동안 제한적으로 보관될 수 있습니다.

관련 문서

자세한 데이터 처리 내용은 FocusDay 개인정보처리방침을 확인해 주세요.
